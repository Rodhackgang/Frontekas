## Présentation

Génère une liste de numéros de téléphone français à partir d'une plage, pour constituer rapidement un carnet de contacts de test.

**Pourquoi ce choix.** Tester un système de messagerie ou une campagne suppose une liste de numéros valides en format. La produire à la main est fastidieux.

---

## Ce que fait le projet

- Génération par plage
- Export de la liste obtenue
